# xplrclose

This is my first minecraft mod project. Also a first real java project. So there could be a couple of bugs. Im still learning, and will add more features as the time goes on (:

## What it does
- Notification in the bottom right + a ping sound when a player enters your radius (20 blocks by default)
- Red box around nearby players so you can see where they are, even through walls
- Ignore players you trust (friends, teammates) so they stop alerting you


  Open chat (`T`) to click the notification buttons:
- **X** closes the notification
- **Ignore** closes it and stops alerts for that player

## Installation
1. Install [Fabric Loader](https://fabricmc.net/use/) 0.20.1+ for Minecraft 26.3
2. Put [Fabric API](https://modrinth.com/mod/fabric-api) in your `mods` folder
3. Download `xplrclose-x.x.x.jar` from [Releases](https://github.com/majcek210/xplrclose/releases) and put it in `mods` too

## Version
Only supported current version:
> - 26.3

Older versions are not supported, sorry.

## Ingame commands
/xplrclose ignored
/xplrclose unignore playername

## Local development
